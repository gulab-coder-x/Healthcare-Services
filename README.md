# Healthcare Services Portal

A static multi-page portal for healthcare services and test forms.

## Pages
- **[Home Portal](index.html)**: Main landing portal with navigation to services and tests
- **[General Test Form](generaltest.html)**: Patient information and registration form
- **[MMSY Test Form](mmsytest.html)**: Mukhyamantri Mahila Samman Yojana form
- **[Ayushman Bharat Test Form](ayushmanbharattest.html)**: Ayushman Bharat scheme test form

## GitHub Pages Deployment
This repository is configured to be hosted directly on GitHub Pages.
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Set branch to `main` and folder to `/ (root)`.
4. Save. Your site will be published at `https://<username>.github.io/<repository-name>/`.
